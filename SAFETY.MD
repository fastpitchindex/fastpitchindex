# Safety Rules (Non-Negotiable)

1) No deletions, moves, or renames without my explicit approval.
2) No "big refactors" or multi-file rewrites in one step.
3) Always show a file list of intended changes BEFORE editing.
4) Edit incrementally: max 3 files per step unless approved.
5) Never overwrite existing files; create new files with .new suffix if unsure.
6) All secrets go in .env.local and are never committed.
7) Every milestone ends with a git commit.
